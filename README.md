# Build a Computer

A drag-and-drop game for primary students (Years 3–6). Students put the main parts of a **desktop computer** or a **laptop** in the right places, read a short fact card for each part, turn the computer on, and then do a picture quiz.

- One self-contained file: `build-a-computer.html` (no images, fonts or libraries to load)
- Works with mouse, touch (iPad, Chromebook) and keyboard
- Easy / Challenge levels, read-aloud fact cards, optional sound
- Teacher notes inside the game (the **Teacher** button)

Curriculum: Australian Curriculum v9, Digital Technologies, Years 5–6, **AC9TDI6K01**: investigate the main internal components of common digital systems and their function.
